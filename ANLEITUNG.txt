INSTALLATION ALS APP (ANDROID):
1. Alle Dateien dieses Ordners gemeinsam auf einer HTTPS-Webadresse veröffentlichen (z.B. GitHub Pages).
2. Die Adresse in Chrome öffnen.
3. Chrome-Menü (drei Punkte) > App installieren bzw. Zum Startbildschirm hinzufügen.
4. App-Icon erscheint auf dem Startbildschirm.
